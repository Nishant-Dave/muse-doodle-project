# Panda animation assets

Original artwork generated by `tools/generate_artwork.py` (Pillow). All frames
are 240x240 PNG with transparent backgrounds. Re-run the script from the
project root to regenerate:

    python3 tools/generate_artwork.py

## Animations

| Animation      | Frames | FPS | Loop | Used for |
|----------------|--------|-----|------|----------|
| `idle`         | 3      | 2   | yes  | Default resting state; gentle bob |
| `blink`        | 3      | 9   | no   | Idle personality (also "Okay" mood ack) |
| `yawn`         | 4      | 3   | no   | Idle personality; sleepy reaction |
| `drag`         | 2      | 5   | yes  | While the panda is being dragged |
| `poke`         | 3      | 7   | no   | Click/tap reaction: surprise -> happy |
| `happy`        | 3      | 6   | no   | "Happy" mood reaction |
| `dizzy`        | 4      | 5   | no   | After a long (>120px) or slow (>1.5s) drag |
| `mood_sad`     | 2      | 2   | no   | "Sad" mood reaction |
| `mood_stressed`| 2      | 4   | no   | "Stressed" mood reaction |

`manifest.json` maps each animation name to its frame files, fps, loop flag,
and description. `AssetLoader` reads this manifest; unknown names fail
gracefully (warning + no-op).
